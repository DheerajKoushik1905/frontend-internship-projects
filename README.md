## Run the HTML/CSS/JS projects

Open the project's `index.html` directly in a browser, or use a local development server such as VS Code Live Server.

## Run a React project

```bash
cd 06-react-components-practice
npm install
npm run dev
```

Use the same commands inside `07-react-blog-ui`.
