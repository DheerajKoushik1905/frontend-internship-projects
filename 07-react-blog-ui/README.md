# React Blog UI — Mini Project

A small React-based blog interface that loads post content from a local JSON file and supports search and filtering.

## Requirements covered

- React-based blog layout
- Post cards rendered from `src/data/posts.json`
- Real-time text search
- Category filtering
- Reusable components
- Responsive design
- Empty state and reset controls

## Run

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```
