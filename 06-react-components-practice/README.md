# React Components Practice

A Vite + React project demonstrating the five required reusable components:

1. `Header`
2. `Footer`
3. `Card`
4. `Button`
5. `Form`

## React concepts demonstrated

- Props for reusable content
- `useState` for saved cards, filtering, and form input
- Dynamic rendering with `.map()`
- Conditional rendering
- Controlled form components
- Event handling

## Run

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
```
